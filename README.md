**# 💻 Operating Systems Lab

A collection of my **Operating Systems Laboratory programs and implementations** completed as part of my Computer Science coursework.

This repository contains practical programs covering process management, CPU scheduling, synchronization, inter-process communication, memory management, system calls, and other core Operating Systems concepts.

---

## 📚 Lab Topics

### ⚙️ CPU Scheduling
Programs related to CPU scheduling algorithms and process scheduling concepts.

- CPU Scheduling Algorithms
- Process Scheduling

### 🔄 Process Synchronization

Programs demonstrating synchronization between processes and threads.

- Dining Philosophers Problem
- Mutex Locks
- Semaphores
- Deadlock and Synchronization

### 🧠 Shared Memory

Programs demonstrating communication between processes using shared memory.

### 🔗 Inter-Process Communication

Programs related to communication between processes.

- Pipes
- Message Passing

### 🖥️ System Calls

Programs demonstrating Linux/Unix system calls and process-related operations.

### 🧵 Threads

Programs using POSIX threads and synchronization mechanisms.

### 🐚 Shell Programming

Shell scripts for basic Linux operations and problem-solving.
